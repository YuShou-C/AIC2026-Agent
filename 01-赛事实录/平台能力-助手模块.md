# 平台能力实录 · 「蓝鹰敏学」助手（复赛形态）

> 事实底稿：平台类问题以本文为准。来源：队长账号实测（09-02/09-03）+ 对话内截图。
> 09-03 重构：只保留当前有效事实，修正史压缩到文末，过时内容已清。

## 总纲

复赛用「助手」形态，**不是「工作流」**（工作流是总决赛"工作流设计丰富度 40 分"的主战场）。助手无可视化编排——**所有流程逻辑写进系统提示词**（平台原生支持"对整体流程的约束"）。助手对话**不能输入图片**（多模态出局复赛）。

## 五模块速览

| 模块 | 平台能力 | 我方用法 |
|---|---|---|
| 1 系统提示词 | 手写 + 自动扩写画像 + 流程约束 | 粘贴 `04-提示词` 八段式稿；扩写只取润色收益（效果待试搭验证） |
| 2 模型配置 | 8 模型可切、温度、最大历史 token（默认 32000） | 低温度 0.1–0.3；三候选 A/B（见下） |
| 3 开场引导 | 开场白 + 引导问题可增删 | 粘贴 `04-提示词` B/C 节；引导问题按 4 条设计 |
| 4 知识 | 文档知识库（详见下节） | 三文档库挂载 |
| 5 工具 | 内置 / API / MCP | 挂计算器+时间，其余不挂（见下） |

## 模型目录（下拉实测）

- AI大模型：deepseek-v3 / deepseek-r1（推理）/ deepseek-v3.1
- 智谱 AI：glm-4.5 / glm-4.6
- 通义千问：qwen-vl-plus（疑似 VL，助手吃不到图）/ qwen-plus / deepseek-v4-flash-0731（平台默认）

→ 事实问答候选：**deepseek-v3.1 / glm-4.6 / qwen-plus 低温度 A/B**；r1 慢，现场不用。（下拉是否滚到底未确认）

## 知识（关键限制）

- **只有文档知识库可挂载到助手**。QA 知识库功能存在但助手用不了（修正4）→ QA 弹药走「QA 对文档化」，格式见 `05-知识库采集模板`。
- 文档库可挂**多个**（数量上限待试搭验证）。
- 导入向导 4 步：上传 → 分段策略 → 原文对比 → 数据处理；有"预览分段结果"可随时 QC。
- 三种切分策略：**自动**（默认 1000 字符/重叠 0）/ **自定义正则**（可按 `第.{1,3}条` 切）/ **按层级**（适用 MD/Word，可勾"切片追加章节标题"）→ 我方三库统一用按层级（参数在 05 文件）。
- 上传格式：MD/Word 确认；PDF/txt 待确认。

## 工具

- **内置（实测 5 项）**：计算器（Python 算术）/ 时间 / 代码执行器 / 经济金融数据 / 论文获取
- **API 工具**：无预置；自建 = OpenAPI Schema 声明式接入**外部已部署端点**（平台内不写代码）→ 复赛不碰
- **MCP**：内置 15 项（Bing/墨迹天气/航班/可视化图表/豆包多模态/网页读取/天眼查/文件内容抽取/导出WORD-PDF/发现报告/值得买/WebSearch/搜狗百科/百度AI搜索/思维导图）+ 可加服务器 → 复赛全不挂
- **复赛策略：挂内置「计算器 + 时间」**——计算器做税额试算演示（口径必须出自知识库），时间做执行期限校验；演练验证，误调用即摘。不挂的防御话术见蓝图 D6。
- 决赛候选 MCP：豆包多模态（发票拍照识别）/ 文件内容抽取（材料核对器）/ 导出WORD/PDF（说明书下载）
