# 知识库采集模板与规范 v1.0（2026-09-03）

> 用途：弹药库采集的唯一格式标准。队友照模板填，QC 照第 6 节清单过。
> 依据：蓝图 v1.0 D3（三文档库、统一层级切分）+ 修正4（QA 对文档化）。

---

## 1. 总规则（三条库通用）

1. **标题即检索上下文**：平台"按层级切分 + 切片追加章节标题"会把标题带进切片。我们不赌它追加的是就近标题还是全路径——**每个 H2 标题必须自带完整上下文**（域/文件简称 + 主题）。
2. **正文不用标题，只用粗体段名**：防止 H3/H4 触发更细的二次切分把答案切碎。段落名用 `**结论**：` 这种粗体行。
3. **单节 ≤ 800 字**：超过就拆条（QA 拆成两问，政策条拆要点）。留出"预览分段结果"QC 空间（最大切分长度默认 1000 字符）。

**三个库统一参数（现场照抄）**：按层级切分 ｜ 切分层级 2 ｜ 最大切分长度 1000 ｜ 勾选"切片追加章节标题"。

## 2. 模板 A · QA 对库（主力，4 个文件）

**文件组织**（按域一文件，命名带序号=现场导入顺序）：

```
10-qa-发票业务.md      （目标 80–100 条）
20-qa-增值税申报.md    （目标 60–80 条）
30-qa-税收优惠.md      （目标 60–80 条）
40-qa-术语与计算规则.md（目标 40–70 条 = 术语 30–50 + 计算规则 10–20）
```

**条目模板（标准 QA）**：

```markdown
# 发票业务问答库

## 红字发票怎么开？发票开错了如何冲红？（同问：开票信息填错了怎么办；跨月发票能作废吗）

**结论**：……（一句话）
**办理流程**：……（分步）
**材料清单**：……
**政策依据**：《……》（文号；执行期限）。
**风险提示**：……
```

- H2 标题 = 主问题 +（同问：1–2 条同义问法）——同义问法写进标题就是为了 embedding 命中，**必须填**，用用户的口吻写（12366 原问题 + 口语化改写）。
- 五段按需浓缩：流程类必有流程/材料；政策口径类可只有 结论+依据+风险；**结论+政策依据 两段任何条目必须有**。

**术语条目模板**（40 号文件用）：

```markdown
## 什么是征收率？（同问：征收率和税率有什么区别）

**解释**：用一句大白话 + 一个数字例子。
**关联**：与之相对的概念（如 税率 vs 征收率）。
```

**计算规则条目模板**（40 号文件用，试算链的口径来源）：

```markdown
## 小规模纳税人增值税征收率是多少？（同问：小规模开专票按几个点交税）

**规则**：……（口径原文）
**政策依据**：《……》（文号；执行期限）。
```

## 3. 模板 B · 政策库（3 个文件，按域合集）

**文件组织**：

```
11-政策-发票与申报.md
21-政策-增值税申报.md
31-政策-税收优惠.md
```

（域怎么归并以采集实际情况微调，保持 3 个文件、序号 1x/2x/3x 连号即可。）

**结构**：H1 = 政策文件全名+文号；H2 =【文件简称 · 第X条 · 主题词】。切分层级 2 → 每个切片 = 一条政策，标题自带简称与主题。

```markdown
# 财政部 税务总局关于增值税小规模纳税人减免增值税政策的公告（财政部 税务总局公告2023年第19号）

> 发文日期：2023-01-09 ｜ 执行期限：2023-01-01 至 2027-12-31 ｜ 状态：现行有效

## 【19号公告 · 第一条 · 免税标准】
小规模纳税人发生增值税应税销售行为，月销售额10万元以下（含本数）的，免征增值税。
……（条款原文，不改动、不意译）

## 【19号公告 · 第二条 · 减按1%】
……
```

- **条款原文照抄**（这是"依据可查"的根），主题词由采集人标注（3–6 个字，写这条是关于什么的）。
- 文件头那行元信息（发文日期/期限/状态）跟 H1 同块，会随第一个切片入库——可接受；关键期限同时写进涉及条目的正文或主题词。
- 徐毅的转换脚本从法规库原文 → 本模板；主题词目前人工标（脚本做不了的增值部分）。

## 4. 模板 C · 事项库（3 个文件，按域）

```
12-事项-发票业务.md
22-事项-增值税申报.md
32-事项-税收优惠.md
```

**结构**：H1 = 域标题；H2 = 事项名；字段用粗体行（不用 H3）。

```markdown
# 发票业务办税事项

## 红字发票开具（电子税务局）

**适用情形**：……
**所需材料**：……
**办理流程**：1. …… 2. …… 3. ……
**办理时限**：……
**办理渠道**：电子税务局 / 办税服务厅
**政策依据**：《……》（文号）。
```

- 事项名后括号补渠道关键词（如"（电子税务局）"），标题信息更密。
- 一个事项 ≤ 800 字；字段可缺（没有的材料写"无"或删行），**政策依据行不可缺**。

## 5. 采集台账（每文件一份，与 md 同目录）

`采集台账-<文件名>.md`，一行一条，QC 抽查用：

```markdown
| 条目（H2 标题前半） | 来源 URL（12366/税务总局法规库） | 抓取日期 | 录入人 |
|---|---|---|---|
| 红字发票怎么开 | https://… | 2026-09-05 | 徐毅 |
```

md 正文保持干净不塞 URL（防污染 embedding），可核验性由台账承担——这也是"数据 10 分"的采集叙事素材。

## 6. QC 清单（每文件交稿前过一遍）

- [ ] 每个 H2 标题自带上下文（域/简称+主题），单看标题知道这条是关于什么的
- [ ] QA 条目：同问 ≥1 条且是用户口吻；结论+政策依据两段齐全
- [ ] 政策条目：条款原文未改写；主题词已标
- [ ] 所有文号格式统一（"财政部 税务总局公告2023年第19号"式样全库一致）
- [ ] 单节 ≤800 字
- [ ] 台账行数 = md 条目数，来源域名仅 12366/税务总局（chinatax.gov.cn）
- [ ] 文件头 `#` 标题、无 H3/H4、段落名全粗体

## 7. 待试搭验证项（不阻塞采集）

- 切片追加的标题是"就近标题"还是"全路径"（决定标题自包含策略是否冗余，但按第 1 条规则写则两种情况都安全）
- 最大切分长度 1000 是否会截长条（预览里看 40 号文件最长的条目）
- 10 个文件全部挂载 + 层级切分参数的实际导入耗时（喂 D5 时间表）
