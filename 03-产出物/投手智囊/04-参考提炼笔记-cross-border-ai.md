## 一、Agent Prompt 提炼（它怎么写系统提示词）

它的 Prompt 骨架：角色定义（"资深跨境电商运营专家"）→ 核心能力清单（4 项领域）→ 强制规则（5 条）→ 工作流程（问题→检索→组织回答，3 步）。

**可学 3 条**：
1. **兜底句式**："基于检索结果回答，若知识库中没有，诚实说明，再补充通用知识" —— 我方提示词兜底段的参照（我们版要加"降级为投前建议/引导换问法"，比它只说"诚实告知"更进一步）。
2. **引用要求**："回答时引用知识库中的具体数据或规定" —— 与我方四段式输出第④段"依据引用"完全同构，先例验证了这条路。
3. **开场白简短 + 行动引导**（"请直接提出你的问题，我会从知识库检索最准确的答案"）。

**局限 5 条（我方差异化，答辩反面对照素材）**：
1. 强制检索一刀切（"无论问什么都必须先检索"）——简单问题也检索，效率低。
2. **无追问机制**：用户问题缺项时不会澄清（我方节点 1 的核心设计）。
3. 无范围声明（不说自己不做什么）。
4. 无合规层（禁词拦截、风险提示全无）。
5. 兜底单薄：只有一句"诚实告知+补通用"，无引导。

**平台形态差异（重要）**：它的"Agent 决策是否检索"在 n8n 里是工具调用循环；蓝鹰敏学**助手形态的检索由平台 RAG 自动完成，提示词控制不了"检索与否"**——所以我方提示词真正要设计的是"检索内容不足/不命中时的分流话术"，这正是它没做的。

## 二、两篇广告 SOP 的可移植资产（按我方六节点映射）

### 黄金公式（直接进我方 B 层"公式套用"清单）
| 它的公式（亚马逊口径） | 我方转写（国内通用口径） | 用于 |
|---|---|---|
| 建议出价 = 目标 ACOS × 售价 × 预估转化率 | **建议 CPC 出价 = 目标单次转化成本 × 预估 CVR**（ACOS×售价即每单广告成本≈CPA） | 节点 5 建议出价带 |
| 新品总预算 = 目标出单量 × CPC ÷ 预估转化率；所需点击 = 目标 ÷ CVR；所需花费 = 点击 × CPC | **逆向反推链：目标转化数 → 所需点击 → 所需预算**（它 §7.1 瑜伽垫案例 = 完整演算样板） | 节点 4 逆向反推（蓝图修订项的现成公式链） |

### 结构与规则骨架
| 它的资产 | 内容要点 | 映射到我方 |
|---|---|---|
| 广告架构金字塔 | 品牌 10% / 手动精准 40% / 手动广泛 25% / 自动 25%；单组预算下限（低于则数据样本太小） | 节点 6 预算分配规则的占比骨架 + "预算低于门槛提示"规则的先例 |
| 四周预算节奏 | 30/25/25/20，每周有明确目标与广告结构演进 | 节点 6 阶段化预算 SOP 骨架 |
| 按客单价分级 | 低价（<20）/中价/高价（>50）三档，各有预算区间、ACOS 宽容度、分配比例与警告 | 节点 2/6 的"客单价→策略"映射规则 |
| 分阶段指标目标 | 新品 40–80% → 爬升 25–40% → 稳定 15–25%；"不要用统一目标要求所有产品" | 节点 4 可达性判断的宽容度设计（不同客单价/阶段目标不同） |
| 加预算信号清单 | ✅ACOS 达标且量在涨 → 每次 +20–30%、跑 3–5 天再动；❌花费涨转化不涨不加 | 节点 5 调价节奏规则 |
| 预算消耗三态诊断 | 花完刚好/上午花完（价太高或词太大）/花不完（价太低或词太小）→ 对应调整方向 | 投前预期管理的推断逻辑（也是总决赛 D 诊断模块的素材） |
| 诊断表（症状→原因→解法） | 曝光低/点击低/转化低/成本飙升 各有归因与解法 | **复赛不用，总决赛 D 模块现成方法论**（先存档） |
| TACOS 思想 | "高手看 TACOS（含自然流量），新手看 ACOS"——广告不是孤立考核 | 节点 4 预期管理话术：告知广告对整体生意的带动，不只看单次转化 |

### ⚠️ 不可照搬警告（关键）
两篇 SOP 的打法**深度绑定亚马逊搜索广告逻辑**（关键词、广泛/词组/精准匹配、Search Term Report、SP/SB/SD）。国内信息流是**人群包+素材**逻辑，没有关键词匹配体系。**公式、结构、比例、节奏可移植；关键词打法细节一律不搬**，我方 SOP 按人群定向口径自编。

### 术语映射表（防止我方 SOP 混入亚马逊黑话）
| 亚马逊用语 | 国内通用口径 |
|---|---|
| ACOS（花费÷广告销售额） | 广告成本销售比；对照国内常用 ROI（销售额÷花费，倒数关系） |
| TACOS | 含自然流量的整体广告占比 |
| 学习期（Learning phase） | 冷启动期 |
| 自动/手动广告、广泛/词组/精准匹配 | 定向方式（人群包/兴趣/行为）——概念体系不同，不是翻译关系 |
| Search Term Report | 搜索词报告（仅搜索广告场景） |

## 三、SOP 写作模板的参照要点（从两篇正文反推）

1. frontmatter：title / tags / created。
2. 每篇开头一句"本质句"（如"新品期广告的钱，一半买流量，一半买数据"）——给助手的领域直觉。
3. 公式块用代码框 + 演算示例（输入→过程→结论）。
4. 表格密度高；每个大节末尾有可执行清单（✅/❌ 或 checkbox）。
5. 文末"相关笔记"互链（对应我方"一主题一文件"互引）。
6. 我方追加要求：标题含同义问法、每节自包含、层级≤三级（平台切片友好）。
