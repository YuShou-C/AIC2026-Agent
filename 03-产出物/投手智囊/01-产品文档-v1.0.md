## 一、产品定位

「投手智囊」是一个面向中小企业的广告投放策略顾问智能体，基于蓝鹰敏学低代码平台搭建，采用"知识库 + 提示词 + 工作流 + 对话测试"的架构。

核心思路：充分借鉴腾讯广告算法大赛的工业级广告技术思想（用户行为序列、转化预估 pCVR、GSP 竞价、出价单调性、序列建模与特征交互），但将这些算法能力"降维"为可被普通商家直接使用的决策规则与知识库，而非训练黑盒模型。

### 1.1 一句话定位

商家输入"我卖什么、预算多少、要什么结果"，智能体输出"投给谁、出多少价、什么时候投、配什么素材、怎么复盘"的投前策略四件套，并在投放后完成漏斗诊断与复盘。

### 1.2 产品边界（明确不做）

- 不训练 CTR / CVR 预测模型，不评测 AUC——比赛评分看知识库、提示词、工作流、对话质量，而非模型精度。
- 不直接对接广告平台 API 执行投放，只输出可执行策略建议区间。
- 不把匿名特征 ID 翻译成具体业务人群（避免语义臆断）。
- 所有数值标注为"基于行业基准的策略建议区间"，非精确预测。

## 二、目标用户与使用场景

### 2.1 用户分层

| 用户角色 | 核心诉求 | 智能体为其输出的内容 |
|---|---|---|
| ① 线上运营 / 兼职投手（主用户） | 不懂竞价、不敢投、没人投 | 投前策略四件套 + 投后漏斗诊断 + A/B 方案 |
| ② 老板 / 市场负责人（决策用户） | 怕烧钱、看不懂 ROI | 白话版策略摘要、一页复盘、下轮建议 |
| ③ 代运营 / 小广告公司（批量用户） | 多账户、跨平台、标准化 | 按客户建知识库子空间、批量出方案、自动周报 |
| ④ 素材 / 文案（协作用户，可选） | 素材与投放目标不匹配 | 投放目标 → 卖点 → 标题/主图 brief 子节点 |

### 2.2 典型场景

- 投前决策：输入"职业教育、日预算 500、目标 20 个留资"，输出渠道、出价、定向、预算分配、曝光/留资区间。
- 单调性校验：出价从 2 元提到 4 元，其他不变，曝光是否单调上升、成本是否失控。
- 投后复盘：曝光 10 万、点击 2000、留资 10，定位薄弱段并给 A/B 实验方案。
- 合规预审：文案含"全网最低、根治、第一"等禁词时拦截并给替代词。

## 三、腾讯广告算法大赛思路映射

下表是本产品"算法思想 → 智能体落地"的核心设计依据。所有算法思路仅作为决策规则与知识库内容嵌入，不做模型训练。

| 腾讯赛题思路 | 对应本产品模块 | 落地形态 |
|---|---|---|
| 2019 广告曝光预估 + 出价单调性 | A 投前预估（核心引擎） | eCPM 竞争力评估、曝光区间预估、单调性自检节点 |
| GSP 竞价 / eCPM = 出价×pCTR / pCVR | A 出价策略子节点 | CPC / oCPM / CPA 竞价方式判定规则 |
| 2017 / 2026 CVR 预测 + 序列建模 | D 漏斗诊断复盘 | 行为权重规则：浏览<加购<购买/留资 |
| 2018 Lookalike 相似人群拓展 | C 人群定向（扩展位） | 种子客群 → 画像规则 → 定向包建议 |
| 2021 / 2025 多模态 / 全模态生成式推荐 | E 素材策略（可选） | 素材-用户意图匹配、创意评分规则 |

## 四、功能架构与工作流闭环

### 4.1 投前决策（模块 A，含 B）

需求解析 → 渠道 / 竞价方式判定 → 定向人群覆盖 → eCPM 竞争力评估 → 曝光 / 点击 / 转化区间预估 → 出价单调性自检 → 预算分配建议 → 素材 brief。

### 4.2 投后复盘（模块 D）

上传脱敏投放日志 → 漏斗对标行业基准 → 薄弱段定位（素材 / 人群 / 落地页 / 出价）→ 优化假设 → A/B 实验方案 → 复盘报告 → 喂回知识库迭代。

### 4.3 渐进式交付

| 阶段 | 范围 | 目标 |
|---|---|---|
| 复赛（90 分钟） | 仅 A 的 5–6 个节点 | 保"基础搭建 20 分 + 技术实现度 80 分" |
| 总决赛 | 接入 D 复盘工作流 + 知识库微调 | 冲"工作流丰富度 40 分 + 操作分 70%" |
| 赛后扩展 | C 人群包、E 素材 brief | 答辩"未来迭代"页，加分不增负 |

## 五、数据集与知识库方案

数据准备遵循"公开 / 合成数据做基准 + 规则文档做方法论 + 脱敏日志做复盘"，按四类库组织，不追求真实大盘、不训练模型。

| 库类型 | 作用 | 来源 | 入库形式 |
|---|---|---|---|
| ① 规则 / 方法论库 | 出价、竞价、预算、合规判断 | 平台帮助文档、广告法、自编 SOP | Markdown / PDF |
| ② 行业基准库 | CTR / CVR / CPM / CPA 参考区间 | 飞桨 ad_performance.csv + 合成 | 表格 + 说明 |
| ③ 投放样本库 | 投前校准、投后复盘 | 脱敏自有 / 公开 PPC / 合成日志 | 结构化 CSV |
| ④ 对话测试语料库 | 复赛测试、总决赛问题集 | 自写业务问答对 | 问答对 |

### 5.1 主数据源：飞桨 app 广告投放数据集

- 链接：https://aistudio.baidu.com/datasetdetail/55268
- 文件：ad_performance.csv，约 889 行 × 13 字段，公共数据集区可直接下载。
- 字段：渠道代号、日均 UV、平均注册率、平均搜索量、访问深度、平均停留时长、订单转化率、投放总时间、素材类型、广告类型、合作方式（roi/cpc/cpm/cpd）、广告尺寸、广告卖点。
- 用途：按"合作方式 × 广告类型 × 素材类型"分组统计得基准区间；聚类出渠道画像；归纳异常规则（访问深但转化低 → 落地页问题）。

### 5.2 出价单调性：AuctionNet（仅取逻辑骨架）

- 来源：阿里妈妈 NeurIPS 2024 AuctionNet（GitHub: alimama-tech/AuctionNet）。
- 用法：只取 bid → 获胜 → cost → conversion 字段逻辑，写成规则文档；Python 合成出价梯度数据校验单调性，曲线入库。不下载 80GB、不训练强化学习。

### 5.3 腾讯 TAAC2026 demo（方法论参考）

- 来源：HuggingFace TAAC2026/second_round_sample_1000（脱敏转化预估样本，Parquet）。
- 用法：做 EDA，抽象"用户属性 + 广告属性 + 行为序列 + 特征交叉 → 转化预估"的方法论文档进知识库；不把匿名 user_int_feats 翻译成具体人群，不训练模型。

## 六、Python 辅助层规范

Python 仅用于"知识库构建 + 单调性校验"，不替代智能体主交互，避免本末倒置。配套脚本：explore_app_data.py。

- 合成日志：按行业给定 base_CTR / base_CVR、出价、预算，随机扰动生成每日曝光 / 点击 / 转化；出价梯度 1.0/1.5/2.0/2.5/3.0 倍验证曝光单调上升。
- 基准曲线：拟合"出价 → eCPM → 曝光 → 成本"经验表，导出 CSV 供知识库引用。
- 单调性校验：Python 跑 bid → impression，计算排序一致性，输出"通过 / 不通过"说明文档入库。
- 异常检测：规则找"曝光突增 10 倍""CTR < 0.01%"等，生成复盘案例。

## 七、合规边界与评分对齐

### 7.1 合规红线

- 不使用真实客户名、手机号、设备 ID、cookie 级数据；用计划级 / 日级聚合。
- 公开数据注明来源；自编规则、合成基准、SOP 属原创，符合比赛"原创、禁抄袭"要求。
- 知识库做二次加工（投手决策 SOP），不全抄平台帮助中心，分段让"出价单调性 / 冷启动 / 复盘"各自成块。

### 7.2 评分项对齐

| 评分项 | 对应设计 |
|---|---|
| 智能体基础搭建（需求/场景/数据，共 20 分） | 第二章用户分层 + 第五章数据架构 |
| 知识库完成度（20 分） | 四类库 + 二次加工 SOP |
| 提示词（30 / 10 分） | 投前预估 / 单调性 / 复盘三套分层提示词 |
| 工作流设计（40 分） | A + D 闭环节点，总决赛接 C / E |
| 对话质量（10 / 10 分） | 30 条测试用例（含单调性必测题） |
| 创新与商业价值（20 分） | 把算法投手经验平民化、可讲 ROI 提升逻辑 |

## 八、面向智能体的规划输入（关键）

以下内容供 AIC 智能体直接读取并据此进一步规划、拆解任务与排期。

### 8.1 固定约束

- 平台：蓝鹰敏学低代码智能体（知识库 + 提示词 + 工作流 + 对话测试），禁止用 Python 搭建主交互。
- 评分导向：知识库、提示词、架构、工作流、对话质量，不评 AUC。
- 阶段：先复赛精简骨架（A 模块 5–6 节点），再总决赛升级（接 D + 微调）。
- 数据：飞桨 ad_performance.csv 为主、AuctionNet 逻辑 + TAAC demo 方法论为辅助，全部脱敏 / 合成。

### 8.2 待规划的交付物清单

- 知识库字段清单与样例数据（含 Python 生成基准数据脚本）。
- A + D 工作流节点图（输入输出、前后依赖）。
- 分层提示词三套：投前预估 / 单调性校验 / 复盘诊断。
- 30 条测试用例（覆盖投前、单调性、复盘、合规）。
- 总决赛答辩 PPT 框架（8 页）。

### 8.3 需智能体确认的两个决策点

- 知识库数据：使用脱敏真实日志，还是用 Python 生成合成基准数据（推荐合成，合规省事）。
- 复赛版本：先出精简骨架，还是一步到位做完整版。
